# kovka
📖 Описание
Проект представляет собой полноценный веб-сайт кованных изделий, админ-панель и CRM-систему.

🚀 Возможности
Публичный сайт (forgeart-site/): Каталог изделий, карточка товара, отправка заказа на e-mail.

CRM-система (forgeart-crm/): Админ-панель для управления заказами, товарами, сотрудниками и финансами.

API для Android (forgeart-api/): Бэкенд для мобильного приложения сотрудников.

Безопасность: Защита от SQL-инъекций, XSS-атак, CSRF-токены.

🛠️ Технологии
Backend: PHP (нативный код)

Database: MySQL (MariaDB)

Frontend: HTML, CSS, JavaScript, jQuery

Mobile API: PHP (REST)
